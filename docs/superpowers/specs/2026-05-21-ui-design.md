## 2. 아키텍처 개요

```
React (Vite :5173)
  │
  ├── REST  ──────► POST /api/run/{stage}   (파이프라인 단계 실행)
  ├── REST  ──────► GET  /api/status        (현재 상태 폴링, 2s)
  ├── REST  ──────► GET  /api/artifacts     (아티팩트 목록)
  ├── SSE   ──────► GET  /api/logs/stream   (원시 로그 텍스트)
  └── SSE   ──────► GET  /api/metrics/stream (구조화 메트릭 JSON)
        │
        ▼
FastAPI (:8000)
  │
  ├── routes/pipeline.py   → POST /run/{stage}, GET /status
  ├── routes/logs.py       → SSE 로그 스트림
  ├── routes/artifacts.py  → 파일 목록 + 다운로드
  └── subprocess_runner.py → asyncio subprocess 관리
        │  stdout pipe
        ▼
run.py  (env / collect / il / rl / export)
```

### SSE 이벤트 포맷

```
event: log
data: {"line": "[RL] Step 32480 | rew=-0.041", "ts": 1716000000}

event: metric
data: {"step": 32480, "rew_mean": -0.041, "stage": "rl"}

event: done
data: {"stage": "rl", "exit_code": 0}

event: error
data: {"stage": "rl", "exit_code": 1, "msg": "..."}
```

### stdout 파싱 프로토콜

`subprocess_runner.py`가 `run.py` stdout을 줄 단위로 읽으며 정규식으로 파싱:

| 패턴 | 추출 필드 | SSE 이벤트 |
|------|-----------|-----------|
| `[RL] Step (\d+) \| rew=([\d.\-]+)` | step, rew | metric |
| `[IL] Epoch (\d+) loss=([\d.]+)` | epoch, loss | metric |
| `ENV OK` | — | log (stage=env 완료 신호) |
| 그 외 | — | log (원시 전달) |

## 4. 컴포넌트 상세 설계

### 4.1 PipelineBar

5개 스테이지(ENV / COLLECT / IL / RL / EXPORT)를 가로로 나열.

- `done` — 초록 체크 원, 진행선 초록
- `running` — 보라 펄스 애니메이션, 진행선 점선 애니메이션
- `pending` — 회색 원
- `error` — 빨간 원 + 에러 툴팁

```typescript
type StageStatus = 'done' | 'running' | 'pending' | 'error'
interface Stage { name: string; status: StageStatus; detail: string }
```

### 4.2 RewardChart

```typescript
interface MetricPoint { step: number; rew: number; loss?: number; ts: number }
// useSSEMetrics()가 MetricPoint[] 누적 → Recharts LineChart에 전달
// X축: step, Y축: rew_mean / loss (토글 가능)
// 최근 500포인트만 유지 (메모리 관리)
```

### 4.3 LogPanel

```typescript
interface LogLine { ts: number; level: 'INFO'|'WARN'|'ERROR'|'RL'|'IL'; text: string }
// useSSELogs()가 LogLine[] 누적 → 최근 200라인 유지
// 자동 스크롤 (하단 고정, 수동 스크롤 시 일시 중단)
```

### 4.4 ArtifactList

```typescript
interface Artifact {
  id: string; name: string; path: string
  size_bytes: number; type: 'onnx'|'hdf5'|'pt'|'zip'
  created_at: string
}
// GET /api/artifacts → Artifact[]
// 다운로드: GET /api/artifacts/{id}/download → FileResponse
```

### 4.5 useSSELogs hook

```typescript
function useSSELogs(url: string): { lines: LogLine[]; connected: boolean }
// EventSource 연결
// onerror → setTimeout 재연결 (1s → 2s → 4s 상한)
// cleanup: useEffect return () => es.close()
```

## 5. 에러 처리

| 시나리오 | 감지 위치 | 처리 방식 |
|----------|-----------|-----------|
| subprocess 비정상 종료 | `subprocess_runner.py` exit_code ≠ 0 | SSE `event: error` → PipelineBar 빨간색 + 토스트 |
| SSE 연결 끊김 | `useSSELogs.ts` onerror | 지수 백오프 자동 재연결 |
| 단계 중복 실행 | `routes/pipeline.py` | 409 Conflict → Run 버튼 비활성화 |
| 선행 체크포인트 없음 | `routes/pipeline.py` 사전 검증 | 422 + 명확한 에러 메시지 표시 |
| SSE 드롭 중 상태 불일치 | React Query 폴링 | /api/status 2s 폴링이 독립적으로 상태 복구 |

| 레이어 | 도구 | 범위 |

## 7. 실행 방법

```bash
# 1. 백엔드 의존성 추가
pip install fastapi uvicorn sse-starlette

# 2. 백엔드 실행
uvicorn api.main:app --reload --port 8000

# 3. 프론트엔드 설치 및 실행
cd dashboard
npm install
npm run dev       # http://localhost:5173

# 4. 브라우저 접속
# http://localhost:5173
# Vite가 /api/* → localhost:8000 자동 프록시
```
